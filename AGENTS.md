# Agent memory

Long-term memory is not in this repo. It lives in the private GitHub vault `bennygx234-design/obsidian-brain`.

At the start of every task:

1. Refresh the vault. Prefer a workspace folder named `obsidian-brain`. If it is missing, clone or fetch `https://github.com/bennygx234-design/obsidian-brain` (GitHub tools if git cannot authenticate) and pull `main`.
2. Read `cursor-context/ALWAYS.md`, then `NOW.md`, then `MEMORY.md`.
3. Open `cursor-context/PROJECTS.md` and read pack `tks-orbslam3`, plus any other pack Benny named. Read only those files, plus extra MEMORY.md links that match the exact task.
4. After a real change, update the matching vault note, add a MEMORY.md pointer if the note is new, commit and push the vault.

Do not load unrelated notes. Never write secrets into the vault.
